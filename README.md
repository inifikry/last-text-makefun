# Last Text at One Percent

The funniest final text a dying phone sends at one percent battery —
in the phone's own voice, under 200 characters.

> okay, confession: i've been at 0% for the last hour. the 1% was a lie. i just wanted to see how this ends. it ends like thi

The phone confesses it has been lying about the battery all along, and
then dies mid-word, mid-sentence.

## Run

```sh
python3 main.py
```

Writes the message to `/output/entry.txt` (123 characters, deterministic —
every run produces the exact same file).
